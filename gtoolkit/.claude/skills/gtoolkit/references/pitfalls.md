# Pitfalls seen while driving GT from Claude

Each of these happened on GT v1.1.601.

| Symptom                                                             | Cause                                                                                                  | Do this                                                                                                                                                                 |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GT's MCP server stopped answering for good; GT had to be killed     | an evaluation wrote to a class variable that did not exist (`UndeclaredVariableWrite`)                 | before code writes a new class variable, check `Class classVarNames`. `createClassesAndTraits` does **not** change an existing class; use `changeClassOrTraitSignature` |
| `createClassesAndTraits` created nothing, reported `isError: false` | `traits` is required even when empty                                                                   | always send `"traits": []`; read the tool's text, not only `isError`                                                                                                    |
| `BrEditorWrongThreadError`                                          | widgets built from the MCP worker process                                                              | queue UI work with `BlTaskAction enqueueElement: <a GtWorld> root action: [...]`                                                                                        |
| a queued task never ran                                             | queued on the "Scripter" space, which runs no frames                                                   | queue on `GtWorld allInstances detect: [ :w                                                                                                                             |
| strings come back as `''ok''`                                       | GT doubles every quote in `objectPrintString`                                                          | the model undoes it (`string` field); in raw tool output undouble once                                                                                                  |
| a long result is cut with `[..]`                                    | print strings stop at 50 000 characters                                                                | write the result to a file from Smalltalk and read the file                                                                                                             |
| a GT window is missing from the list                                | `BlSpace allInstances` skips subclasses                                                                | use `allSubInstances`                                                                                                                                                   |
| `doesNotUnderstand: #or:or:` / `#ifEmpty:ifNotEmpty:`               | no such message / not on `LeSnippets`                                                                  | nest `or:`; convert with `asArray`                                                                                                                                      |
| Lepiter tool says "not found" for a knowledge base                  | knowledge bases are addressed by `uuidString`                                                          | get ids from `lepiterKnowledgeBases`                                                                                                                                    |
| an eval call blocks until a forked job finishes                     | a job forked at `userBackgroundPriority` ran ahead of the reply                                        | keep evals short; poll state in a later call                                                                                                                            |
| everything is gone after a restart                                  | classes, settings and objects live in the image                                                        | save the image (model `stop save=true` or snapshot); Lepiter pages persist on their own                                                                                 |
| dark theme left white boxes, black-on-grey text, green shadows      | GT's dark theme is incomplete (hard-coded colours, cached inherited theme, a green placeholder shadow) | leave GT's look alone unless the user asks; it was tried and reverted                                                                                                   |

Before saving an image, keep a way back: the original download archive or a copy
of the image.
